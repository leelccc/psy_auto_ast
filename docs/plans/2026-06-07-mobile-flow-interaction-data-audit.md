# 移动端用户流程、交互与数据流审计

日期：2026-06-07  
适用范围：`apps/mobile` 当前 MVP 原型  
依据：`progress.md`、`task_plan.md`、`docs/prd/session-memory.md`，并以用户后续明确修订为最高优先级。

## 1. 决策优先级

当文档互相冲突时，采用以下顺序：

1. 用户最近一次明确确认。
2. `task_plan.md` 中已记录的后续决策。
3. `docs/prd/session-memory.md`。
4. 早期 PRD 与设计稿。

当前已知冲突：

- 早期 PRD 将归档次数设计为用户选择项。
- 后续已确认规则为：已有档案按已完成记录自动顺延，新档案从第 1 次开始。
- 因此归档页只有“身份类型”和“归属档案”是用户决策；记录编号是只读确认结果。

## 2. 核心用户流程

### 2.1 录音与归档

```text
首页开始录音
-> 录音中（暂停 / 继续 / 取消 / 保存）
-> 保存后进入归档确认
-> 选择来访者 / 督导师 / 受督者
-> 搜索并选择已有档案，或新增人员
-> 系统计算固定记录编号
-> 确认归档
-> 原始录音进入 14 天临时保存
-> 异步生成转写、纪要、章节
-> 进入对应档案的本次记录
```

关键规则：

- 正在录音页不展示历史录音。
- 保存录音不等于完成归档。
- 原始录音不能授权长期保存。
- 归档记录编号一旦生成应固定，删除旧记录不能导致编号重排。

### 2.2 录音记录

```text
录音记录列表
-> 待归档：进入归档确认
-> 生成中：进入处理状态详情
-> 可查看且已归档：进入录音纪要详情
-> 生成失败：在原始录音仍存在时允许重新生成
-> 已销毁：仅展示销毁状态，不提供播放或重新生成
```

### 2.3 档案库

```text
档案 Tab
-> 按身份筛选
-> 按姓名 / 编号 / 状态搜索
-> 进入档案时验证该身份的访问密码
-> 查看档案详情
```

新增档案：

```text
新增档案
-> 选择身份
-> 填写该身份必要字段
-> 创建基础档案
-> 进入新档案详情
-> 新档案显示“尚无记录”，不能伪造第 1 次记录
```

### 2.4 单次记录

```text
档案详情的某次记录卡
-> 录音：录音文件、纪要与下载状态
-> 记录：本次咨询记录 / 督导反馈 / 督导记录
-> 量表：本次量表文件
-> 作业：本次作业文件
-> 其他：本次其他 PDF / 图片
-> 汇总可用材料生成本次记录草稿
-> 编辑
-> 保存为正式版
-> 可选择授权长期保存
```

### 2.5 个案报告

```text
档案详情
-> 生成个案报告
-> 展示全档案可用资料清单
-> 默认勾选可用资料，允许取消
-> 已销毁资料不可选择
-> 生成草稿
-> 编辑 / 保存正式版 / 导出 / 授权长期保存
```

单次记录不能叫“个案报告”；个案报告不能只基于一次咨询。

### 2.6 数据与隐私

```text
我的
-> 数据与隐私
-> 即将销毁资料 / 已长期保存资料
-> 选择可授权资料
-> 阅读保存范围、期限、风险和撤回规则
-> 主动确认授权
-> 后续可撤回
```

关键规则：

- 默认不勾选。
- 原始录音可以出现在即将销毁列表，但不能出现在可授权或已长期保存列表。
- 撤回时若原 14 天期限已过，资料立即销毁。

## 3. 交互行为规则

所有视觉上可点击的元素必须符合以下一种结果：

1. 导航到明确页面。
2. 改变可见状态，并允许继续下一步。
3. 打开需要用户决策的弹窗或表单。
4. 执行动作并显示可核对的结果。

禁止：

- 用 Toast 代替本应存在的页面、列表、表单或状态变化。
- 把系统自动计算结果做成可点击步骤。
- 所有录音列表项无差别进入同一详情页。
- 新建成功后仍展示旧人物或硬编码资料。
- 静态文字伪装成筛选器、搜索框或按钮。
- 显示“上传、编辑、更多、全部”等动作，但没有下一层内容。

反馈规则：

- Toast 只用于轻量完成反馈，不承载核心任务。
- 删除、覆盖、重新生成必须二次确认并说明影响。
- 禁用状态要说明缺少什么条件。
- 页面返回必须回到发起动作的上下文。

## 4. 数据流转

### 4.1 核心实体关系

```text
Profile 档案
  -> Session 单次咨询 / 受督 / 督导
    -> Recording 原始录音（仅 14 天）
    -> Transcript 转写（14 天或授权长期）
    -> Summary 录音纪要（14 天或授权长期）
    -> Attachment 量表 / 作业 / 其他（14 天或授权长期）
    -> SessionRecord 本次记录草稿 / 正式版（14 天或授权长期）
  -> CaseReport 全档案个案报告草稿 / 正式版（14 天或授权长期）
```

### 4.2 状态传播

- 归档完成后：录音获得 `profileId`、`sessionId`、固定 `sequenceNumber`。
- 转写或纪要编辑后：后续生成本次记录必须使用最新确认内容。
- 新增量表、作业或附件后：本次记录显示“材料已更新”，已有草稿需要提示重新生成是否覆盖。
- 正式版存在时：重新生成只覆盖草稿，不覆盖正式版。
- 删除资料后：引用位置只保留“资料已删除/销毁”状态，不保留敏感正文。
- 授权长期保存只改变被选资料的生命周期，不改变原始录音生命周期。

## 5. 当前页面审计

| 页面 | 当前问题 | 处理决定 | 优先级 |
|---|---|---|---|
| 首页 | “全部”“7 天”看似按钮但没有实际页面或筛选状态 | 无对应能力前删除可点击样式；保留静态标题信息 | P1 |
| 正在录音 | 取消只有说明，没有二次确认状态 | 增加取消确认；保存继续进入归档 | P1 |
| 录音记录 | 所有状态都进入同一录音纪要详情 | 按待归档、生成中、可查看、失败、销毁分别路由 | P0 |
| 归档确认 | 已修复自动编号被误做成步骤的问题 | 保留当前两步决策 + 只读结果摘要 | 已完成 |
| 归档完成 | “咨询记录材料”对督导师/受督者文案不应固定为咨询 | 根据身份显示受督记录/督导记录材料 | P1 |
| 档案库 | 搜索是假输入框，身份筛选只弹提示，列表未过滤 | 实现真实搜索和身份筛选 | P0 |
| 新增档案 | 字段不可填写，创建后不产生档案 | 实现身份字段、校验、创建并进入空档案 | P0 |
| 档案详情 | 三种身份仍大量使用“咨询”固定文案 | 按身份切换历程、记录和协议名称 | P0 |
| 单次记录卡 | 录音、量表、作业、其他多数只弹说明 | 补资料列表/上传决策页；无能力前不伪装已完成 | P1 |
| 录音纪要 | 编辑章节、完整文本、导出、重新生成多为 Toast | 建立可编辑状态与覆盖确认；导出显示真实任务结果 | P1 |
| 本次记录编辑 | 段落编辑不可操作，草稿/正式版只是说明 | 实现编辑状态、保存状态和版本切换规则 | P0 |
| 长期保存授权 | 选择有效，但确认后不更新资料状态或返回来源页 | 授权后更新状态并返回来源上下文 | P0 |
| 个案报告 | 只有范围说明，没有资料选择和报告页面 | 新增资料选择、生成草稿和正式版流程 | P0 |
| 智能督导 | 添加资料、发送仅 Toast；缺会话列表、引用和停止 | 作为独立阶段实现，不用静态聊天冒充完整能力 | P1 |
| 资讯 | 当前属于轻量静态内容，可接受 | 去掉没有列表支撑的“更多”动作 | P2 |
| 我的 | 数据与隐私入口混入授权弹窗，缺独立管理页面 | 拆分管理页与单次授权弹窗 | P0 |
| 安全设置 | 三项均为 Toast | 后续建立设置页；当前不展示虚假状态变化 | P2 |

## 6. 实施顺序

1. P0 主数据路径：录音状态路由、档案筛选/创建、身份文案、记录版本、授权状态、个案报告。
2. P1 内容操作路径：附件、转写纪要编辑、取消/覆盖确认、智能督导。
3. P2 支撑页面：资讯更多、安全设置、统计详情和日程完整页。

每一批修改必须：

- 先写行为测试。
- 浏览器走完整用户路径。
- 检查文案是否与身份、状态、生命周期一致。
- 删除没有真实结果的动作，而不是继续增加解释型 Toast。

## 7. 2026-06-07 已落地的 P0 修正

- 档案库：搜索和身份筛选已接入真实状态；新增档案可填写、校验、创建并进入新档案。
- 新建档案：普通新增显示 `尚无记录` 空状态，不再伪造第一次记录。
- 录音列表：待归档、生成中、已完成已归档分别进入归档确认、处理状态、录音纪要详情。
- 录音详情：标题、时长、摘要、发言人角色、转写片段和生成记录类型跟随所选录音。
- 归档确认：使用所选录音的标题和时长，并保留返回来源。
- 记录编辑：咨询记录、督导反馈、督导记录按身份切换；草稿可编辑，正式版只读，修改需复制为草稿。
- 数据与隐私：新增独立管理中心；授权弹窗确认后更新已长期保存列表；原始录音不可授权。
- 个案报告：新增资料选择、不可用资料排除、草稿编辑、正式版保存、导出和长期保存授权入口。
- 专注流程：录音、归档、档案创建、记录编辑、个案报告和授权隐藏底部主导航。
- 录音取消：已改为两步确认，第二次确认后丢弃未保存录音并返回首页。

## 8. 2026-06-21 第三轮全局交互复审

本轮复审范围继续覆盖移动端所有主 Tab、专注页面、编辑页、隐私安全页和 AI 督导页。判断标准仍沿用第 3 节：每个看起来可点击的控件必须产生明确导航、状态变化、决策确认或可核对结果。

### 8.1 已直接修正

| 页面 / 组件 | 问题 | 调整 |
|---|---|---|
| 通用分区标题 | 右侧的“必选”“3 项”等静态状态使用与真实动作相同的强调色，容易被误认为按钮 | 新增静态状态样式；只有绑定 `onAction` 的文案保留动作样式 |
| 录音记录编辑 | “编辑段落 3 段”是硬编码，增删段落后状态不可信 | 改为根据实际段落数量显示 |
| 个案报告导出 | Web 与原生端都提示“打开系统分享面板”，Web 端事实不成立 | 按平台显示浏览器下载或系统分享面板文案 |
| 隐私中心 | “即将销毁资料”为 0 时只有空白列表，用户不知道是未加载还是没有资料 | 增加空状态，明确当前无 14 天内到期资料 |
| 隐私中心 | 点击“长期保存”后只刷新列表，没有可核对反馈 | 增加授权成功提示，说明资料已进入长期保存 |
| 智能督导 | 无当前会话时点击“添加资料”会打开空选择区，逻辑断裂 | 改为打开会话列表并提示先创建会话 |
| 智能督导 | 用户消息在左、AI 在右，与常见聊天阅读方向相反 | 改为用户右侧、AI 左侧 |
| 智能督导 | 发送按钮使用播放图标，语义不一致 | 替换为发送图标 |
| 我的 - 安全 | “手机日历同步”显示硬编码“隐私标题模式关闭”，与真实设置可能不一致 | 加载真实日历同步和隐私标题状态后展示 |
| 安全设置 | 永久注销账号按钮禁用时视觉仍像可点击危险按钮 | 增加禁用态透明度 |
| 登录页 | Web 预览在 390px 宽度下卡片可能横向溢出 | 容器宽度改为基于窗口计算，移动端自适应 |
| 首页 / 统计页 | 标题写“本周统计”，实际数据是全部已归档录音 | 统一改为“累计统计” |
| 新建档案 | 联系方式、主诉 / 方向等输入项当前不会保存，容易形成“填了但丢失”的体验 | 移除未持久化字段，只保留姓名、编号、下次安排，并补稳定字段标签 |
| 智能督导 | 发送失败时输入内容已被清空，用户需要重新输入问题 | 失败时恢复原问题到输入框，并保留错误提示 |
| 个案报告资料选择 | 生成中按钮虽然禁用，但视觉仍像可点击 | 生成中复用禁用主按钮样式 |
| 日程页 | 系统日历同步开关没有保存中禁用态，也没有说明关闭后对既有系统事件的影响 | 保存中禁用开关；开启 / 关闭后分别提示真实影响 |
| 日程页 | 隐私标题模式切换后只改变开关，没有解释锁屏 / 系统日历暴露影响 | 切换成功后提示开启或关闭的隐私后果 |
| 归档确认 | 新增人员按钮文案写“保存人员并选中”，但实际创建发生在最终确认归档时 | 改为“选中此新人员”，提示确认归档后才会创建档案 |
| 归档确认 | 新增人员备注占位像基础档案字段，实际保存为本次 session 摘要 | 改为“本次记录摘要”，并补稳定字段标签 |
| 安全设置 | 手机日历同步和隐私标题模式缺少保存中禁用态与成功后的风险说明 | 保存中禁用；成功后说明系统日历与锁屏显示影响 |
| 个案报告资料选择 | 没有资料或所有资料不可用时，只剩禁用按钮，用户不知道下一步 | 增加“暂无资料 / 没有可参与分析资料”空状态 |
| 个案报告资料选择 | 资料列表变化时，默认勾选可能残留旧资料状态 | 资料变化时重置默认选择和覆盖确认状态 |
| 隐私中心 | 长期保存资料删除确认按钮缺少删除中视觉反馈 | 补充删除中禁用态 |
| 安全设置 | 保存档案访问密码可重复点击 | 增加保存中状态和按钮禁用 |
| 编辑页 | 本次记录 / 个案报告保存正式版、复制草稿可快速重复提交 | 增加操作中状态、禁用主按钮并显示“正在保存 / 正在复制” |
| 档案详情 | 新增记录提交后立即收起表单，失败时用户难以保留输入 | 增加创建中状态；仅后端创建成功后收起表单 |
| 档案详情 | 法律及伦理文件上传 / 替换可重复点击 | 增加上传中状态，单次只处理一个文件位置 |
| 单次记录卡 | 保存摘要先提示成功但后端更新仍在进行 | 改为等待后端更新完成后再收起编辑并提示成功 |
| 单次记录卡 | 删除记录没有删除中状态，可能重复触发 | 增加删除中状态与按钮禁用 |
| 文件预览 | 替换、下载、删除文件时缺少进行中状态 | 增加替换中 / 下载中 / 删除中反馈和重复触发保护 |
| 录音纪要 | 重新生成可重复触发，且生成中可打开旧记录 | 增加生成中状态；生成中禁用进入记录按钮 |
| 章节 / 转写编辑 | 保存按钮没有保存中状态，且章节页存在未使用状态 | 接入保存中状态并移除无用状态 |
