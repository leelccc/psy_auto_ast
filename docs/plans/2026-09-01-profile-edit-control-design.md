# 档案基本信息编辑入口设计

## 目标

把档案详情头部的「编辑基本信息」从卡片底部的大型通用操作降级为姓名旁的辅助操作，使姓名、身份和档案状态继续成为视觉主角。

## 已确认方案

- 入口位于档案姓名右侧，三类档案使用同一位置。
- 视觉为 30px 高的暖米色胶囊，不使用普通描边矩形按钮。
- 左侧使用陶土色 22px 圆形徽记，内部放白色 Lucide `Edit3` 图标；右侧仅显示「编辑」。
- 使用轻微暖灰阴影表达层次，按下时背景变深、整体下沉 1px，不使用渐变、发光或网页 hover 动效。
- 通过 `hitSlop` 把有效触控范围扩展到 48px，并提供明确的无障碍标签。
- 长姓名保持单行并允许收缩，不能挤掉编辑入口和右侧「已解锁」状态。

## 行为边界

点击后继续打开既有 React Native `Modal` 编辑表单；字段、保存接口、错误处理和关闭规则均不改变。本批次只调整入口的层级、位置与视觉反馈。
