# 咨询历程录音选择边界

## 结论

“录音记录”是创建录音的唯一入口。用户在这里现场录音或上传文件；每一次录制、每一个上传文件始终形成一条独立录音，一条录音只能对应一个音频文件。

咨询历程内的“录音”资料页只读取外部录音记录中 `archive_status=unarchived` 的录音，并允许用户选择 1–5 条归入当前咨询历程。该页面不提供现场录音、本地上传或片段编辑入口。

## 交互流程

1. 用户在“录音记录”创建录音或上传音频。
2. 用户进入某次咨询历程的“录音”资料页，从未归档列表中多选 1–5 条录音，合计不超过 300MB。
3. 系统只完成归档关联，不自动开始 AI 转写。
4. 归档成功后进入“整理录音片段”页，用户可以试听、排序或从本次咨询中移除已选录音，但不能继续录制或上传。
5. 用户确认片段与顺序，并主动点击“开始转写”。
6. 开始转写后，录音片段及顺序永久锁定。

当未归档列表为空时，页面只提示用户前往“录音记录”创建或上传，不在咨询历程内复制创建能力。

## 状态与错误

- 已归档录音不会出现在其他咨询历程的候选列表中。
- 当前咨询历程已有录音时，后端继续拒绝关联第二条录音。
- 归档失败时保留候选列表并显示错误；不会启动转写。
- 转写仍由录音整理页的二次确认触发。

## 验收

- 每条外层录音始终只有一个音频文件。
- 咨询历程可选择 1–5 条未归档录音，合计不超过 300MB。
- 咨询历程录音页不存在“开始新录音”和“上传本地音频”。
- 选择未归档录音后，其归档状态更新，并且不会自动调用转写接口。
- Web 窄屏下候选列表、空状态和片段整理页无横向溢出。
